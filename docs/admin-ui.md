# Админка

Локальная панель: сводка, очередь предложений, блокировки, правила, настройки,
проверка текста. Отдельный процесс на `127.0.0.1:8788`.

## Запуск

```powershell
python -m redactrail.admin --root . --port 8788 --no-browser
```

В едином приложении (`python -m redactrail.app`) админка поднимается вместе
с прокси. Браузер открывается вручную: **http://127.0.0.1:8788/**.

Токен создаётся при первом старте (`state/admin-token`). Вход:
`http://127.0.0.1:8788/admin` ставит cookie без ручного ввода токена; для
скриптов — заголовок `X-Admin-Token`.

## Доступ

- только loopback; наружу не выставлять;
- `Host`/`Origin` сверяются с портом; чужие origin отклоняются;
- мутации — `POST` с токеном или same-origin;
- значения показываются только по клику, в журналы не попадают.

## Что читает и пишет

| Путь | Назначение |
|---|---|
| `audit/*.jsonl` | запросы, блокировки, предложения |
| `policy.json` | действующая политика; правка с бэкапом и diff |
| `state/` | ключ, токен, кеш, бэкапы, журналы |

## Разделы

| Раздел | Что делает |
|---|---|
| Сводка | запросы, разные значения, блокировки, часы, кеш, последний запрос |
| Очередь | предложения аудита и правила; принять/отклонить, применить |
| Блокировки | журнал блокировок, «Показать», «Разобрать блокировки» |
| Правила | действия классов, маркеры, allow, `extra_rules`, лимиты |
| Изменения | что будет записано в `policy.json`, diff и бэкап |
| Процессы | прокси, модель, аудит, автозапуск, журналы |
| Настройки | режим, изображения, секреты, маркеры |
| Проверка | прогнать текст через текущую политику |

Принятое правило из очереди пишется в `policy.json` → `extra_rules`; находка
помечается `covered`, чтобы не висеть в ожидании. Прокси подхватывает политику
на следующем запросе.

Повторный прогон очередь не раздувает: одинаковый `id` из файлов разных дней
показывается одной строкой (побеждает более поздняя запись), а технические
идентификаторы (`dsh-runtimes`, `anonymous-user-id`) в очередь не попадают.

## Автозапуск и перезапуск

Автозапуск — задача планировщика `redactrail`, `pythonw.exe` без консоли и
браузера. В едином процессе кнопка «Перезапустить прокси» не убивает процесс:
политика и так перечитывается, для смены кода приложение перезапускают вручную.

## Ограничения

- не предназначена для сети и многопользовательской работы;
- аудит и значения доступны только там, где лежат сессии DSH;
- кеш и статистика считаются в памяти процесса прокси.
