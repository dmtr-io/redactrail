# Как внести вклад

Спасибо за интерес к проекту. Это локальный прокси для DeepSeek Harness (DSH):
Windows-first, только стандартная библиотека Python.

Если вы используете AI-ассистента, сначала дайте ему `AGENTS.md`: там команды,
ограничения и определение готовности.

[Русский](CONTRIBUTING.md) · [English](CONTRIBUTING.en.md)

## Подготовка

- Windows 10/11, Python 3.12+.
- Никаких сторонних runtime-зависимостей. Не добавляйте `pip install` в путь
  прокси или админки.
- Аудит: `python -m redactrail.review`; для zstd-сессий нужен Python 3.14
  или `zstd` в `PATH`.

```powershell
copy policy.example.json policy.json   # локальная политика, не коммитить
python -m unittest discover -s tests -t .
powershell -ExecutionPolicy Bypass -File scripts/test.ps1
```

`scripts/test.ps1` запускает тесты и гейт бенчмарка. Pull request должен
оставлять его зелёным.

## Тесты и фикстуры

- **Только синтетические данные.** Не вставляйте реальные имена, телефоны,
  адреса, ключи и логи сессий в тесты, корпус, скриншоты.
- Новое поведение детектора — тест в `tests/corpus/` или `tests/test_entities.py`.
- Новое поведение прокси — end-to-end тест в `tests/test_proxy.py`.
- Для тестов используйте `policy.example.json`; `policy.json` локальный и
  игнорируется git.

## Стиль кода

- Только стандартная библиотека; типы на публичных функциях.
- Детекторы детерминированы и fail-closed: неизвестная форма блока
  отклоняется, а не пересылается.
- Не логируйте значения. Только хеши, классы и длины.
- Обновляйте `CHANGELOG.md` для пользовательских изменений.

## Чек-лист pull request

- [ ] тесты добавлены или обновлены;
- [ ] `scripts/test.ps1` зелёный;
- [ ] в коде, фикстурах, docs и скриншотах нет реальных персональных данных;
- [ ] нет новых runtime-зависимостей;
- [ ] запись в CHANGELOG;
- [ ] описано влияние на модель угроз.
